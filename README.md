# Proyecto-final-de-redes-ciclo-1-2026
Proyecto académico de diseño y simulación de una infraestructura de red empresarial para un edificio de tres niveles. Incluye diseño físico y lógico, cableado estructurado, backbone de fibra óptica, direccionamiento IP mediante VLSM, enrutamiento con RIPv2, simulación en GNS3 y documentación técnica.
